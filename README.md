# 🖼️ Understanding Digital Images

A digital image can be represented as a collection of **pixels**.

For a color image, each pixel generally contains information from different color channels.

### RGB Representation

```text
             Image
               │
       ┌───────┼───────┐
       ↓       ↓       ↓
      Red    Green    Blue
       │       │       │
       └───────┼───────┘
               ↓
        Final Color Image
```

Understanding pixels and color channels is an important foundation for Computer Vision because most image-processing operations work directly with this underlying numerical representation.
